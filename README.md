# Shikimori Explorer — База Персонажей, Семейных Связей и Real-time Синхронизация

Интерактивное веб-приложение для вашего ПК: быстрый поиск любого аниме, манги или ранобэ, сбор всех персонажей по связанным частям франшизы (сезоны, фильмы, OVA, Specials, манга), автоматическое построение интерактивного семейного дерева (Shikimori + Wikidata + Anime Characters Database), поиск цепочек родства и авто-синхронизация со свежими сериями в реальном времени.

---

## ⚡ Как использовать и запускать на вашем ПК

Проект полностью автономен, работает прямо на вашем компьютере и **не требует установки сторонних библиотек**.

### Способ 1: В один клик (самый простой)
1. Просто дважды кликните по файлу:
   👉 **`start.bat`**
2. Он автоматически откроет сайт в вашем браузере по адресу **http://localhost:3000** и запустит сервер!

---

### Способ 2: Через командную строку (Terminal / PowerShell / CMD)
1. Откройте терминал в папке проекта.
2. Введите команду:
   ```bash
   npm start
   ```
   *(или `node server.js`)*
3. Откройте в браузере: **http://localhost:3000**

> Чтобы остановить сервер, нажмите сочетание клавиш `Ctrl + C` в окне терминала или просто закройте окно.

## 🧭 Возможности и фичи

1. **⚡ SWR Realtime Auto-Sync (Авто-актуализация данных)**:
   - Карточки и деревья открываются **мгновенно (0.01 сек)**.
   - В фоновом режиме сайт автоматически опрашивает сеть (Shikimori, Wikidata, ACDB): если в новой серии раскрыли родителя или обновились данные, сайт **на лету обновляет дерево прямо на экране** и показывает уведомление.

2. **🔗 Поиск родственной связи («Кем они приходятся друг другу?»)**:
   - Кнопка **«Найти родство»** в шапке: выберите любых двух персонажей (например, *Наруто* и *Цунаде*), и алгоритм графа найдет кратчайшую цепочку связи:
     `Персонаж 1 ──[Отец]──> Персонаж 2 ──[Сестра]──> Персонаж 3`.

3. **🙈 Режим защиты от спойлеров (Spoiler Shield)**:
   - Тумблер в шапке: размывает имена и лица скрытых родственников матовым стеклом. Спойлер открывается только при наведении курсора.

4. **⭐ Избранное (Favorites)**:
   - Сохраняйте любимых персонажей и важные деревья в 1 клик с помощью кнопки **⭐**. Панель быстрого доступа доступна в шапке.

5. **📷 Экспорт дерева в PNG**:
   - Кнопка **«Экспорт PNG»** в модальном окне: генерирует красивую графическую карточку родословного дерева для публикации в Discord, Telegram или соцсетях.

6. **🧬 Фильтр по кланам и династиям**:
   - Автоматически находит кланы (Учиха, Хьюга, Узумаки, Аккерман...) и создает быстрые фильтры над каталогом персонажей.

7. **⚡ Скорость и оптимизация**:
   - Встроенное аппаратное сжатие Gzip (размер скриптов уменьшен на 75%).
   - ETag / HTTP 304 кэширование статики.
   - CSS `content-visibility: auto` и `loading="lazy"` для плавного скролла 500+ персонажей.

## 📁 Структура проекта

- `start.bat` — лаунчер для быстрого запуска в один клик на Windows.
- `server.js` — локальный сервер Node.js со сжатием Gzip и 304 ETag.
- `public/`
  - `index.html` — разметка сайта со стеклянным дизайном.
  - `style.css` — стили, анимации, адаптив и Glassmorphism.
  - `app.js` — логика SWR, семейных деревьев, графов родства и экспорта в PNG.
- `api/`
  - `search.js` — поиск по Shikimori.
  - `anime.js` / `manga.js` — данные о тайтлах.
  - `roles.js` — персонажи франшизы.
  - `character.js` — профиль персонажа (с поддержкой `fresh=1`).
  - `related.js` — связанные тайтлы франшизы.
  - `shiki-find.js` — умный поиск персонажей по именам.
  - `wikidata-relations.js` — связи и родственники из Wikidata.
  - `acdb-relations.js` — связи из Anime Characters Database.
- `lib/`
  - `shikimori.js` — клиент с двухуровневым кэшированием, защитой от банов 429 и поддержкой live-обновления.
